# Backend — يا مساعد

FastAPI لفهم التذكيرات باللهجة المصرية، وتحويل تسجيل WAV إلى نص عربي باستخدام
`faster-whisper` وSilero VAD. فهم التذكير بقواعد محددة دون LLM.

## التشغيل

من مجلد `backend` باستخدام Python 3.11–3.13 و[uv](https://docs.astral.sh/uv/):

```bash
uv sync --frozen --group dev
uv run uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

قيد `av>=11,<17` مقصود للتوافق مع `faster-whisper 1.2.1`:
PyAV 19 أزال وسيط `metadata_errors` الذي يستخدمه فك ترميز التسجيلات.
ملف القفل يثبت الإصدار الذي اختُبر (`av 16.1.0`).

واجهة OpenAPI: `http://localhost:8000/docs`.
`GET /health` و`POST /parse-reminder` يعملان دون تنزيل موديل صوت.
تنزيل Whisper يحدث عند أول تسجيل صالح فقط؛ يحتفظ الجهاز بالموديل في cache.
التشغيل الافتراضي CPU، موديل `small` و`int8`.

للجهاز الذي يدعم CUDA مع مكتبات CTranslate2/CUDA المطلوبة:

```bash
WHISPER_DEVICE=cuda WHISPER_MODEL=large-v3-turbo WHISPER_COMPUTE_TYPE=float16 \
  uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

إعدادات اختيارية (لا تحتاج مفاتيح API):

| المتغير | الافتراضي | الاستخدام |
| --- | --- | --- |
| `WHISPER_DEVICE` | `cpu` | `cpu` أو `cuda` |
| `WHISPER_MODEL` | `small` / `large-v3-turbo` مع CUDA | اسم موديل مدعوم أو مسار موديل محلي |
| `WHISPER_COMPUTE_TYPE` | `int8` / `float16` مع CUDA | نوع حساب متوافق مع الجهاز |
| `WHISPER_DOWNLOAD_ROOT` | cache المكتبة | مكان حفظ الموديلات |
| `MAX_AUDIO_BYTES` | `10485760` | حد الملف: 10 MiB |
| `MAX_AUDIO_SECONDS` | `120` | أقصى مدة تسجيل |
| `CORS_ORIGINS` | فارغ | origins المتصفح مفصولة بفاصلة؛ Flutter Android لا يحتاجه |

تنزيل موديل Whisper يحتاج اتصال Hugging Face. تعذر التنزيل أو غياب runtime مناسب
يعيد `503`؛ راجع سجل الخادم وأصلح السبب ثم أعد تشغيله. `/health` يعرض حالة
الصوت `not_loaded` أو `loading` أو `ready` أو `error` بصدق؛ `status: ok` يشير إلى
استجابة API ولا يؤكد جاهزية موديل الصوت.

## واجهات API

### `POST /parse-reminder`

```json
{
  "text": "عندي محاضرة الخميس الساعة ثلاثة العصر فكرني قبلها بساعتين",
  "timezone": "Africa/Cairo",
  "now": "2026-10-19T12:00:00+03:00"
}
```

`now` اختياري للاختبار، ويجب أن يحتوي UTC offset إذا أرسلته. في الاستخدام العادي
يرسل التطبيق `text` و`timezone`، ويستخدم الخادم الوقت الحالي. التاريخ والوقت في
النتيجة يحتويان timezone offset. مثال:

```json
{
  "title": "محاضرة",
  "date": "2026-10-22",
  "time": "15:00",
  "event_datetime": "2026-10-22T15:00:00+03:00",
  "reminder_datetime": "2026-10-22T13:00:00+03:00",
  "remind_before_minutes": 120,
  "missing_fields": [],
  "ambiguous_fields": [],
  "question": null
}
```

النواقص تظهر في `missing_fields` والغموض في `ambiguous_fields` ومعهما `question`
للسؤال التالي. مثال: «خمسة» دون صباح/مساء تحتاج تأكيدًا قبل الحفظ. يستكمل التطبيق
البيانات بإرسال `context` مع الرد التالي:

```json
{
  "text": "خمسة العصر",
  "timezone": "Africa/Cairo",
  "context": {"title": "دكتور", "date": "2026-10-20"}
}
```

حقول `context`: `title` و`date` بصيغة `YYYY-MM-DD` و`time` بصيغة `HH:mm`
و`remind_before_minutes`. لا يحفظ الخادم محادثات أو تذكيرات؛ التخزين والجدولة
محليان في Flutter.

يفهم المحلل بكرة وبعد بكرة، وأسماء أيام الأسبوع (أقرب يوم قادم؛ نفس اسم اليوم
يعني الأسبوع القادم)، والتواريخ `DD/MM/YYYY` و`YYYY-MM-DD` وأسماء الشهور العربية.
«خمسة العصر» و«17:00» واضحتان؛ «خمسة» و«05:00» تحتاجان إعادة الوقت كاملًا مع
صباح أو مساء. الرد «مساء» وحده لا يكمل ساعة سابقة لأن قيمة الساعة الغامضة لم
تُحفظ. ردود مثل «أيوه» تحافظ على العنوان السابق؛ تغييره يكون بصيغة صريحة مثل
«العنوان دكتور أسنان».

يدعم مدة التذكير بالدقائق والساعات، الربع والنصف والثلث، و«في نفس الموعد»
للتذكير وقت الحدث. لا يحول تعبيرًا غير مدعوم إلى مدة أقصر. التاريخ غير الصحيح،
ووقت الحدث أو التذكير الذي فات، والساعة المتكررة أو غير الموجودة عند تغيير
التوقيت الصيفي تحتاج تصحيحًا قبل الحفظ. حساب المدة يستخدم دقائق فعلية عبر UTC.

### `POST /transcribe`

```bash
curl http://localhost:8000/transcribe \
  -F 'file=@voice.wav;type=audio/wav'
```

يرسل Flutter `multipart/form-data` بحقل اسمه `file`: WAV PCM، ويفضل mono
16 kHz، بحد 120 ثانية و10 MiB. يدعم التحقق PCM غير مضغوط، قناة أو قناتين،
8–48 kHz. يتحقق الخادم من الملف الحقيقي قبل تحميل Whisper، ويحذف النسخة المؤقتة
بعد الطلب في النجاح والفشل. النتيجة:

```json
{"text": "عندي دكتور بكرة الساعة خمسة"}
```

`413`: الملف كبير. `415`: صيغة غير WAV. `422`: ملف تالف، مدة زائدة، أو لا يوجد
كلام واضح. `503`: موديل أو runtime غير متاح. التسجيلات لا تُحفظ على الخادم.

## التحقق

```bash
uv run pytest
uv run ruff check .
```

اختبارات API تستبدل Whisper بموديل وهمي لاختبار الطلبات، VAD، التنظيف، وحالات
الفشل دون تنزيل موديل. دقة تحويل الصوت تحتاج تجربة تسجيلات عربية حقيقية على
الجهاز المستهدف؛ راجع خطة التقييم في توثيق المشروع.

### تجربة صوت فعلية — 19 أكتوبر 2026

تم تنزيل `small` وتشغيله فعليًا على CPU بنوع `int8`، مع
`faster-whisper 1.2.1` و`av 16.1.0`. استخدمت تجربة HTTP عبر ASGI عينة
[Arabic.mp3 من Speech-data/arabic-speech-dataset](https://huggingface.co/datasets/Speech-data/arabic-speech-dataset/blob/main/Arabic.mp3)
بمدة 33.96 ثانية، بعد تحويل محلي مؤقت إلى WAV mono 16 kHz. ترخيص المصدر
`CC BY-NC-ND 4.0`؛ العينة خارج المستودع.

- `/transcribe` أعاد `200` ونصًا عربيًا خلال 12.56 ثانية، يشمل تحميل الموديل من cache.
- احتوى النص أخطاء مثل «سوطية» بدل «صوتية»؛ يلزم تقييم أوسع وتسجيلات تذكيرات مصرية.
- ثانية صمت أعادت `422` ورسالة عدم وجود كلام واضح خلال 0.05 ثانية.
- انتقلت حالة `/health` من `not_loaded` إلى `ready`، ولم تتبق ملفات رفع مؤقتة.
- طابق SHA-256 لملف الموديل بصمة HF LFS المعلنة:
  `3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671`.

هذه تجربة واحدة لإثبات تشغيل المسار الصوتي؛ مجموعة الـ20 جملة البشرية المطلوبة
في خطة المشروع ما زالت تحتاج التسجيل والتقييم على جهاز الاستخدام.
