# معاك — مساعد المواعيد العربي

تطبيق **Flutter / Android** لتسجيل المواعيد يدويًا أو بالصوت، مع **FastAPI**
لتحويل الكلام باستخدام Whisper وفهم المواعيد باللهجة المصرية بقواعد واضحة دون LLM.

## التشغيل من Android Studio على اللاب

التحديث الحالي يستخدم **Whisper large-v3-turbo** و**Habibi-TTS المصري EGY**
على اللاب، والتطبيق يعمل داخل محاكي Android. الردود صوت WAV من Habibi، دون
إعداد محركات صوت Google أو Samsung. بعد نجاح الاختبار يمكن تشغيل نفس المصدر
على الهاتف وبناء APK له.

ابدأ من [خطوات Windows وAndroid Studio والمحاكي](docs/android-studio-windows.md).
توجد سكريبتات إعداد وتشغيل، وتنزيلات مثبتة البصمات تعيد استخدام الموديلات التي
حمّلتها سابقًا. [النماذج والعينة المرجعية](docs/model-setup.md).

## تحميل النسخة التجريبية

- [تحميل كود المشروع ZIP](https://github.com/amrelmaidomy/project/releases/download/v0.3.0/ma3ak-source.zip).
- [تفاصيل الإصدار وبصمات الملفات](https://github.com/amrelmaidomy/project/releases/tag/v0.3.0).

على اللاب نزّل كود المشروع، وجهّز الموديلين والخادم ثم شغّل التطبيق من Android Studio.
عند التشغيل من Android Studio يستخدم المحاكي عنوان `10.0.2.2:8000`. الهاتف يحتاج
بناءً بعنوان `127.0.0.1:8000` وربط USB كما في الخطوات أدناه. نداء **«يا رفيق»** يستخدم Whisper على اللاب؛ لا يحتاج تنزيل
نموذج كلمة عربي منفصل. [تشغيل النداء والمحادثة في الخلفية](docs/rafiq.md).

## الموجود

- واجهة عربية من اليمين لليسار، إضافة وتعديل وحذف وإكمال التذكيرات.
- SQLite عبر Drift، مع حفظ التوقيت كـUTC وعرضه حسب توقيت الجهاز.
- جدولة تنبيهات محلية دقيقة، والتحقق من إذن الإشعارات والمنبّهات، واستعادتها بعد إعادة التشغيل.
- تسجيل WAV أحادي القناة 16 kHz وإرساله إلى Whisper `large-v3-turbo` على CPU/int8 افتراضيًا؛
  دعم إعداد `large-v3-turbo` على CUDA.
- Silero VAD، ردود مصرية عبر Habibi-TTS/Vocos على الخادم، وعرض النص الذي سمعه المساعد.
- محادثة تجمع اسم الحدث والتاريخ والساعة ومدة التذكير، ثم تطلب **تأكيد وحفظ**.
- نداء «يا رفيق» اختياري: رد صوتي ومحادثة وحفظ بعد تأكيد صريح، من خدمة ميكروفون
  Android مستقلة عن الواجهة، مع إشعار دائم وزر إيقاف.
- التعامل مع الأرقام العربية والمصرية، بكرة وبعد بكرة وأيام الأسبوع، والربع والنصف،
  وطلب إعادة الوقت مع صباح/مساء عند الغموض. لا يتم اختراع وقت مفقود.

التطبيق يستخدم المنطقة الزمنية للجهاز في الإدخال اليدوي وفي طلبات التحليل. الخادم
يدعم `Africa/Cairo` افتراضيًا، ويرجع أوقاتًا تحتوي UTC offset. التنبيهات نفسها لا
تحتاج تشغيل الخادم أو الاتصال بالإنترنت بعد حفظ التذكير.

## التشغيل

المتطلبات: Flutter **3.35.7**، Android SDK 36 وأدوات35 لبعض الإضافات، JDK17 أو21
كامل يحتوي `javac`، Python3.12 و`uv` لتشغيل الخادم وبيئة Habibi المستقلة.
المنصة المستهدفة Android8.0 فأحدث. ملفات قفل Python وDart موجودة.

على Windows اتبع [سكريبتات الإعداد والتشغيل](docs/android-studio-windows.md)؛
تشغيل بيئة API وحدها لا يجهز Habibi. للمطورين على Linux، من جذر المستودع:

```bash
uv sync --project backend --frozen --group dev
uv sync --project backend/tts_runtime --frozen --no-dev --python 3.12
uv run --project backend --frozen --no-dev python scripts/prepare-models.py
bash scripts/start_backend.sh
```

في طرفية ثانية، على محاكي Android:

```bash
cd mobile
flutter pub get --enforce-lockfile
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

للجهاز الحقيقي استخدم HTTPS للخادم، أو وصّل الجهاز عبر USB ثم:

```bash
adb reverse tcp:8000 tcp:8000
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

نسخة debug تسمح بـHTTP إلى المحاكي وloopback فقط. نسخة release تحتاج عنوان HTTPS
صالحًا وشهادة موثوقة؛ لا يتم تعطيل TLS. أدخل العنوان عند بناء نسخة حقيقية:

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://your-backend.example
```

العنوان الافتراضي في المصدر هو عنوان المحاكي `http://10.0.2.2:8000`؛ حدّد عنوان
الهاتف صراحةً عند تشغيله أو بنائه كما سبق. التذكيرات اليدوية تعمل دون خادم؛
التسجيل وفهم الجمل والرد بصوت Habibi تحتاج الخادم. بناء Debug مخصص للاختبار.

راجع [توقيع نسخة Android](mobile/android/README.md) قبل التوزيع.
لبيئة Codex الحالية، شغّل `source scripts/cloud_env.sh` لتفعيل الأدوات والمجلدات
القابلة للكتابة، ثم `bash scripts/start_backend.sh` أو `bash scripts/check.sh`.
لا تحتاج مفاتيح API. لا ترفع ملفات `.env` أو مفاتيح توقيع Android إلى Git.

## مثال المحادثة

```text
أنت: عندي دكتور بكرة
المساعد: الساعة كام؟ قول صباحًا أو مساءً.
أنت: خمسة العصر
المساعد: أفكرك قبل الموعد بقد إيه؟
أنت: بساعتين
المساعد: يعرض الموعد الساعة 17:00 والتنبيه الساعة 15:00
أنت: تأكيد وحفظ
```

«خمسة» وحدها تحتاج إعادة الساعة كاملة مع صباح/مساء. الصياغة الصريحة تمنع اختيار
توقيت غير مقصود. يمكن كتابة الجمل بدل التسجيل، وتصحيح التفاصيل قبل تأكيد الحفظ.
الصوت يُرسل للخادم عند طلب التحويل، وتُحذف الملفات المؤقتة بعد الطلب؛ المواعيد
والمحادثة لا تُحفظ على الخادم. يحتفظ التطبيق بالتذكيرات محليًا.

## التحقق وحدود التقييم

```bash
cd backend
uv run pytest
uv run ruff check .
cd ../mobile
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --debug --no-pub
```

اختبارات Python تغطي محلل المواعيد وعقود API والتحقق من الصوت والتنظيف والأخطاء.
اختبارات Flutter تغطي SQLite فعلية، اتساق التنبيهات عند فشل الحفظ/الجدولة، وتأكيد
المحادثة وإلغاء التسجيل. بدائل خدمة الإشعارات في الاختبارات لا تثبت ظهور إشعار
Android فعلي.

نتائج تشغيل الموديلات الفعلية، زمن التوليد وحدود جودة الصوت موثقة في
[سجل التحقق](docs/validation.md). نجاح اختبارات API والبناء لا يثبت دقة التعرف
على20 جملة تذكير مصرية أو جودة كل رد. تشغيل الموديلين على GPU لم يُختبر هنا.

يلزم تنفيذ [اختبارات الهاتف](docs/android-device-checks.md) للتحقق من التنبيه بعد
إغلاق التطبيق وإعادة التشغيل، ودقة الصوت على الجهاز المستهدف. الإيقاف الإجباري
من إعدادات Android يمنع التنبيهات حتى فتح التطبيق مجددًا؛ حذف التطبيق يمسح مواعيده.

## نداء «يا رفيق»

افتح صفحة المساعد واضغط **تشغيل يا رفيق**، واسمح بالميكروفون والإشعارات والمنبّهات
الدقيقة. اترك الخادم شغّالًا؛ على الهاتف اترك الـUSB وربط `adb reverse` أيضًا.
المحاكي يتصل مباشرةً بعنوان `10.0.2.2`. بعدها تستطيع الضغط على
Home أو قفل الشاشة والنداء «يا رفيق»، ثم انتظار الرد قبل قول الموعد.
عند اكتمال التفاصيل يقرأ الموعد ووقت التذكير ويسأل عن التأكيد؛ قل **تأكيد** أو
**أيوه احفظ** للحفظ، أو **إلغاء** للتراجع. زر «إيقاف» في الإشعار يقفل الاستماع.

هذا المسار يقطّع الصوت عند الكلام على الهاتف ثم يرسل المقاطع إلى Whisper large-v3-turbo في
خادمك؛ وبالتالي قد يُرسل كلام قريب لا يحتوي النداء طالما الاستماع مفعّل. لا تُرسل
فترات الصمت، ولا يحتفظ الهاتف أو الخادم بملفات المقاطع بعد المعالجة. يحتاج الاتصال
طوال المحادثة، واستهلاكه للطاقة أعلى واستجابته أبطأ من نموذج كلمة محلي متدرّب.
لا يبدأ تلقائيًا بعد reboot أو الإيقاف الإجباري. [التفاصيل والخطوات](docs/rafiq.md).

التحقق المحلي يغطي المنطق والبناء؛ الرد مع الشاشة المقفولة ودقة النداء والبطارية
تحتاج [اختبار الهاتف](docs/android-device-checks.md). تكامل ONNX القديم وتجربة
Hey Jarvis الإنجليزية موثّقان منفصلًا في [توثيق النماذج](docs/wake-word.md).

## بنية المشروع

```text
mobile/       Flutter، Riverpod، Drift، خدمات الصوت والتنبيهات، مضيف Android
backend/      FastAPI، Whisper، قواعد الأرقام والتاريخ والمحادثة، اختبارات
docs/         خطة التحقق على جهاز حقيقي وتقييم المراحل المتبقية
scripts/      تشغيل الخادم وتفعيل أدوات البيئة والتحقق
```

إعداد GitHub Actions موجود لتشغيل الاختبارات وبناء APK عند رفع المستودع. راجع
[صفحة Actions](https://github.com/amrelmaidomy/project/actions) لحالة التشغيل عن بُعد؛
نتائج التحقق المحلي موثقة بصورة مستقلة أدناه.

نتائج التنفيذ الفعلية وحدود ما تم اختباره في [سجل التحقق](docs/validation.md).
